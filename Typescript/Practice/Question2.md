Problem 2: Storage Container HierarchyDescription:
You are managing a collection of rectangular storage sleeves in a warehouse. Each sleeve is described by its width and height, and can be nested inside another sleeve only when both its width and height are strictly less than the outer sleeve's width and height. Sleeves cannot be rotated. Given a 2D array of integers envelopes where envelopes[i] = [w_i, h_i] represents the width and the height of a sleeve, return the maximum number of sleeves that can be nested together in one stack.   Note: You cannot rotate a sleeve.   Example 1:Input: envelopes = [[5,4],[6,4],[6,7],[2,3]]   Output: 3   Explanation: The maximum number of sleeves you can nest is 3 ([2,3] => [5,4] => [6,7]).   Example 2:Input: envelopes = [[1,1],[1,1],[1,1]]   Output: 1   Explanation: None can contain another, so the maximum is 1.   Constraints:$1 \le \text{envelopes.length} \le 10^5$   $\text{envelopes}[i].\text{length} == 2$   $1 \le w_i, h_i \le 10^5$
